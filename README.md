# Buttercup

Buttercup is a mobile-first website concept for the Manchester pudding brand.

## Current build

- Brand-led cream / burgundy / yellow visual system inspired by Buttercup's supplied Instagram identity
- Responsive launch-focused homepage
- Standalone-site announcement and location reveal CTA
- Current menu preview using verified Buttercup flavours
- Dedicated menu page
- Dedicated ordering prototype with basket interactions
- Build-your-own pudding concept
- Catering CTA and email enquiry route
- Instagram integration
- Responsive mobile navigation
- SEO metadata and accessible navigation labels

## Current business context

Buttercup's nine-month Deansgate General Store residency at 9 Owen Street ends on 31 August 2026. The brand has announced its first standalone Manchester site for autumn 2026, but the new address has not yet been revealed. The website therefore treats the new location as **coming soon** rather than presenting the old residency as the permanent location.

The new standalone concept is expected to retain the signature banana pudding and build-your-own format, while introducing new flavours, refreshed toppings including cookie dough bites and brownies, a drinks menu in development, and rotating specials.

## Demo notes

Product imagery is currently represented with lightweight CSS art so the site does not depend on unapproved third-party photography. Approved Buttercup photography can replace these assets later without changing the customer journey.

Pricing in the order prototype is clearly labelled as historical reference pricing and should be replaced with confirmed current pricing before any production launch.
