# Buttercup

Buttercup is a mobile-first dessert brand website concept for the Manchester pudding brand.

## Current build

- Responsive Buttercup homepage
- Brand-led cream / burgundy / yellow visual system
- Sticky responsive navigation
- Hero section with primary ordering CTA
- Bestseller menu preview
- About / brand story
- Location section
- Catering CTA
- Current order-channel handoff
- Instagram and email links
- Mobile navigation interaction

## Next build stages

1. Replace placeholder product visuals with approved Buttercup photography/assets.
2. Build a full menu and product detail experience.
3. Build a dedicated basket/order flow.
4. Add real ordering integration when Buttercup confirms its preferred ordering provider.
5. Add final SEO, analytics, accessibility and production QA.

## Brand direction

The visual direction is grounded in Buttercup's Instagram logo: warm cream, deep burgundy/red, playful organic typography and friendly dessert-first presentation.
